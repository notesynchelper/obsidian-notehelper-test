# 笔记同步助手 Test（notehelper-test）

NoteHelper 插件的 **测试通道**，供 BRAT（Beta Reviewers Auto-update Tool）安装与自动更新。

- 在 BRAT 中添加：`notesynchelper/obsidian-notehelper-test`
- 本仓库只发布构建产物（GitHub Releases 里的 `main.js` / `manifest.json` / `styles.css`），不包含源码。
- 插件 id 为 `notehelper-test`，与正式包（`notehelper`）可在同一 vault 内共存，但请勿同时启用两者。
- 正式渠道：插件内置自动更新 / [obsidian-wechat-messenger](https://github.com/notesynchelper/obsidian-wechat-messenger) / [obsidian-bijitongbu](https://github.com/notesynchelper/obsidian-bijitongbu)
